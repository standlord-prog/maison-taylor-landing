# Сервер Maison Taylor (Supabase)

Первый этап: аккаунты брендов, заказы каталожных фото, загрузка фото вещи, кадры со всеми версиями,
правки по кадрам, наша библиотека моделей и стилизации, наш рабочий экран.

## Что где

| Файл | Что это |
|---|---|
| `migrations/20261011000000_catalog_photos.sql` | Бренды, заказы (вещи), фото бренда, 8 кадров, версии кадров, правки и их цены, права доступа, хранилища `sources` и `shots`. |
| `migrations/20261011000100_library.sql` | Библиотека: модели, обувь, сумки, украшения, фоны и их фото; карта стиля бренда; что пошло в генерацию каждой версии; журнал ошибок по кадрам. Хранилище `library`. |
| `tests/` | Проверка прав доступа на обычном Postgres (`supabase_stub.sql`, потом миграции, потом `rls_test.sql`). |
| `tools/import_library.py` | Заливка библиотеки с Mac: папка на вещь, `item.json` и фото. |
| `../studio.html` | Кабинет бренда: новый заказ, загрузка фото, 8 кадров, правки, версии, утверждение. |
| `../ops.html` | Наш экран: заказы, загрузка кадров, правки брендов, библиотека. |
| `../config.js` | Адрес сервера и публичный ключ проекта maison-taylor. Если очистить, страницы снова работают как превью. |

## Как устроено

- Бренд видит только свои заказы и файлы. Наши версии кадров бренд не видит, пока мы не нажали «Показать бренду».
- Цена правки считается на сервере по прайсу (`edit_price`), браузер её не задаёт.
- Каждая загрузка кадра — новая версия, старые не удаляются; бренд может вернуть любую.
- Генерация пока делается нами: заказ приходит в «Заказы» на `ops.html`, мы загружаем 8 кадров, отмечаем проверки и показываем бренду. Правки приходят в «Правки».
- Библиотека: у каждой модели и вещи несколько фото по ролям (в рост, лицо, спина, крупно), свойства (рост, размер, доля головы), известные проблемы генератора. Бренд выбирает из одобренных; свои аксессуары бренд может загрузить, мы их проверяем.
- У каждой версии кадра записано, каким генератором, по какому заданию и с какими фото из библиотеки она сделана. Ошибки кадров пишутся в `shot_issues` с привязкой к модели или вещи, чтобы видеть, кто чаще даёт брак.

## Запуск (один раз)

1. Создать проект на supabase.com (регион US East). Тариф Free для начала.
2. SQL Editor: выполнить по очереди оба файла из `migrations/`.
3. Authentication → Providers: включить Email (ссылка на вход) и Google.
   Authentication → URL Configuration: Site URL `https://maison-taylor.com`, Redirect URLs `https://maison-taylor.com/studio.html`.
4. Войти на `https://maison-taylor.com/signin.html` своим адресом, потом в SQL Editor добавить себя в команду:
   `insert into staff (user_id, name) select id, 'Андрей' from auth.users where email = 'ваш@адрес';`
5. Project Settings → API: скопировать Project URL и anon key в `config.js`. Ключ `service_role` в сайт не класть никогда, он только для `tools/import_library.py` на Mac.
